# 진선미 / Jinseonmi — UI 목업 (design reference)

> 이 폴더는 **디자인 참고용 정적 목업**이다. `web/` 실제 앱과 연결되지 않으며, 모든 제품·클리닉·수치·환율·영상은 **샘플 값**이다(화면 상단 배너로 표시).
> 기획 근거: `docs/strategy/strategy_26102413_통합플랫폼_최종기획안.md`

## 실행

`index.html`을 브라우저로 연다(설치·서버·키 불필요).

- `index.html` — 첫 실행 온보딩부터
- `index.html?demo` — 샘플 데이터가 채워진 Home
- `index.html?demo&tab=explore` / `?demo&tab=explore&domain=medical` / `?demo&tab=trip`
- `index.html?demo&lang=ko` — 한국어 화면
- 설정(⚙️)에서 데모 초기화·튜토리얼 다시 보기·온보딩 다시 하기

## 기획안 대응

| 기획안 | 목업 |
|---|---|
| §3.0 기본 온보딩 | 언어 → 국가(통화 자동) → 성별·연령(선택, "응답 안 함") → 상세 취향(건너뛰기) |
| §3.0 튜토리얼 | 하단 메뉴 위 1·2·3 안내, 건너뛰기 |
| §3.0 통합 Home | 광고 영역(실제 랭킹과 분리 표기), 뷰티·의료 혼합 추천 + 추천 이유, 카테고리 카드 |
| §3.0 하단 메뉴 | Home / Explore / My Trip, 현재 메뉴 표시. Settings는 미정이라 헤더에 둠 |
| §3.1 Explore | 뷰티·의료 전환, 리얼 랭킹·스폰서 탭 분리, 협찬 여부 칸(협찬 표시 없음/협찬 있음/확인 못 함), 숏폼 자리, 한국 대안 찾기 |
| §3.2 카트·통화 | 원화 합계 + 샘플 환율 환산(실시간 아님 표기), 서로 다른 제품 가격 비교에 "할인 아님" 표기 |
| §3.3 My Trip | 선택적 취향, 방문지, 경로(지도 자리 — 제공자 미정), 일정 상태(제안 → 내가 승인, 클리닉은 "의료기관 확인 대기") |
| §5-1 국가별 추천 | 국가 근거가 없으면 "국가 근거 부족"으로 표시하고 공통 근거 추천 |

## 포팅 시 참고

- 실제 반영은 `web/`의 React 화면에서 한다. 이 목업은 레이아웃·문구·상태 표현만 참고한다.
- `shots/`는 headless 브라우저로 찍은 화면 캡처다.
